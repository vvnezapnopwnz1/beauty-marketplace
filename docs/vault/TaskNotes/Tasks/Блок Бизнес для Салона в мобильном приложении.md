# Блок «Бизнес» для роли Салон в мобильном приложении

## Описание
Реализовать вкладку «Бизнес» (MoreScreen) для пользователей с ролью salon_admin. Сейчас MoreScreen показывает только данные Мастера, переключатель режимов (RoleModeToggle) присутствует в UI, но данные для салона не подтягиваются.

## Что нужно сделать
- Разделить MoreScreen на два контекста: master / salon
- Для salon:
  - Сводка выручки по салону за день/неделю
  - Управление Мастерами (список, приглашения, статусы)
  - Расписание Салона (рабочие часы салона, `DashboardScheduleRepository.WorkingHours`)
  - Финансы Салона (доход/расходы по всем мастерам, по услугам)
  - Уведомления Салона (если отдельный inbox)
  - Быстрые действия: добавить Мастера, добавить Запись

## Зависимости
- Завершить Блок Бизнес для Мастера (все 4 раздела)
- Backend: убедиться что salon-dashboard API покрывает все нужные данные

## Приоритет
Низкий — делать после завершения Master Business block.
