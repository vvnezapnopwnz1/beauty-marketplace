# План внедрения настройки расписания при первом входе в приложение (Mobile Onboarding)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить полноценный шаг настройки рабочего графика и расписания в мобильный онбординг мастера, чтобы при первом входе в приложение календарь заполнялся на основе реальных часов работы, а не статических плейсхолдеров.

**Architecture:** 
1. В интерактивном прототипе (`mobile.html`) расширить мастер-онбординг новым интерактивным экраном выбора рабочих дней (Пн-Вс или сменный график) и рабочих часов.
2. В реальном приложении на React Native (`rn`) внедрить новый шаг в стек онбординга мастера (`app/(auth)/onboarding`), сохраняя настройки расписания в коллекцию Appwrite (`master_schedules` или документ мастера) перед редиректом на главный дашборд.

**Tech Stack:** React, TailwindCSS / NativeWind, React Native (Expo Router), Appwrite SDK.
